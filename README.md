# Spor Programı Personal

Kişisel bölgesel antrenman takip uygulaması.

## İçerik
- 4 gün / 5 gün antrenman modu
- Gün seçimi
- Hareket listeleri
- Alternatif hareketler
- Set tamamlama takibi
- Dinlenme sayacı
- Yerel kayıt desteği
- PWA / ana ekrana ekleme desteği

## iPhone'da uygulama gibi kullanma
1. GitHub Pages linkini Safari ile aç.
2. Paylaş butonuna bas.
3. **Ana Ekrana Ekle** seç.

## GitHub Pages açma
Repository içinde:
Settings > Pages > Deploy from branch > main / root
